# Option Pricing Project

A self-directed Python project comparing different methods for pricing European options.

## Overview

This project implements and compares:

Black–Scholes model
Cox–Ross–Rubinstein binomial tree
Monte Carlo simulation

The project also includes a coffee futures extension using the cost-of-carry model and the Black–76 model.

## Motivation

My interest in quantitative finance began with the Citi Markets Quantitative Analysis virtual job simulation on Forage.The simulation introduced me to coffee futures, commodity markets, options, cost-of-carry pricing, Black–76, Monte Carlo simulation, hedging and risk management.

This motivated me to build a Python project to understand option pricing and numerical methods in greater depth.

## Main Analysis

The project investigates:

European call and put option pricing;
binomial tree convergence;
Monte Carlo convergence;
standard error;
volatility sensitivity;
comparison between analytical and numerical methods.

For the coffee futures extension, I estimate the fair futures price using cost-of-carry pricing and then compare Black–76 with a Monte Carlo simulation.
